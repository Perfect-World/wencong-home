# 施工与材料细节标准（高标准）

> **性质**：业主对材料与施工的**最低要求**，报价与施工不得低于本文件标准。
> **用法**：每节末尾有「验收清单」，验工时逐项对照打勾。
> **说明**：数值均引自国标 / 行标，标准号已标注；凡行业常见偷工点，用 ⚠️ 标出。
> **项目背景**：约 140㎡，全屋通铺 750×1500 柔光砖（卫生间除外），卫生间 400×400 / 400×800，墙面艺术漆、顶面乳胶漆，有主灯＋回光槽，中央空调单边吊顶，下沉式卫生间两次防水回填，金属衣帽架＋铝合金滑门衣柜，实木门 900×2400。

# 一、水电改造

## 1.1 给水管（PP-R）

**执行标准**：管材 GB/T 18742.2-2017，管件 GB/T 18742.3-2017。

管系列 S 数值越小、壁厚越大、承压越高：

| 管系列 | 公称压力 PN(20℃/50年) | dn20 壁厚 | dn25 壁厚 |
|---|---|---|---|
| S5 | 1.25 MPa | 2.0 mm | 2.3 mm |
| S4 | 1.6 MPa | 2.3 mm | 2.8 mm |
| **S3.2** | **2.0 MPa** | **2.8 mm** | **3.5 mm** |
| **S2.5** | **2.5 MPa** | **3.4 mm** | **4.2 mm** |
| S2 | 3.2 MPa | 4.1 mm | 5.1 mm |

- **本项目要求**：冷水管最低 S3.2；**热水管用 S2.5（dn20×3.4 或 dn25×4.2）**
- 管件（弯头、直接、内丝）**必须与管材同品牌、同压力等级**
- ⚠️ **为什么"只写 PPR 管"会被缩水**：不写 S 与壁厚，供货默认给最薄的 S5（1.25MPa）甚至非标管。热水 60~70℃ 长期使用会爆管。合同必须写成 `dn25×3.5（S3.2/PN2.0）` 这种带壁厚的规格
- 冷热水管**平行间距 ≥150mm**，热水在左（或上）；交叉时热水在上

**走顶 vs 走地**

| 方案 | 优点 | 缺点 |
|---|---|---|
| 走顶 | 漏水立刻可见，维修只拆吊顶，不泡楼下、不砸地砖 | 用管多 25~35%，需吊顶 |
| 走地 | 省料、无吊顶 | 漏水难发现，易漫到楼下，检修要砸地 |

- **本项目要求**：厨卫及主水干管**走顶**；走顶时**热水管必须包橡塑保温棉（厚度 ≥15mm）**，既减少热损也防冷凝滴水
- 打压试验前必须**拍照留档**，各出水口封堵

## 1.2 排水管

- PVC-U 排水管执行 GB/T 5836.1-2018；**选无铅管**
- 主立管 dn110，支管 dn50 / dn75，按器具排水量选
- **地漏、存水弯的水封深度 ≥50mm**（GB/T 27710-2020）

| 型号 | 含义 |
|---|---|
| BV | 铜芯 PVC 绝缘单芯硬线，耐温 70℃ |
| BVR | PVC 绝缘软线（多股） |

| **WDZ-BYJR** | 同上，软线（施工更方便） |

- **本项目要求**：全屋用 **WDZ-BYJ / WDZ-BYJR（无卤低烟阻燃 ＋ 交联）**；高标准指定 **WDZ-BYJR-105（耐热 105℃）**
- 最低门槛为 GB/T 5023 系列；⚠️ 偷工点：标称 2.5mm² 实为 2.0mm²、铜包铝、非标 PVC 绝缘

## 1.4 回路与配电

**必须独立成回路的**：照明（1~2 路）、普通插座、厨房、卫生间、**每台空调单独一路**、冰箱（单独，不与他人共用空开）、中央空调外机、即热热水器。本项目建议 **12~14 个回路**。

- 单回路负载 ≤16A（约 3500W）
- **插座回路（含厨房、卫生间）必须配漏电保护器：30mA、动作时间 ≤0.1s**
- **总等电位联结 ＋ 卫生间局部等电位（LEB）必须做**（JGJ 242-2011、GB 50096-2011）：LEB 箱内联结金属给排水管、金属洁具、采暖管、**卫生间插座 PE 线**、建筑钢筋网；无机械保护的联结铜导线 **≥4mm²**
- ⚠️ **LEB 是最常被省掉的安全项**，必须写进合同并在验收时开箱查看
- 零线入户，各回路零线不得借用邻室回路

## 1.5 穿线管（PVC 电工套管）

执行标准 JG/T 3050-1998，按机械应力分三级：

| 等级 | 代号 | 抗压 | dn20 壁厚（约） |
|---|---|---|---|
| 轻型 | 205 | 320 N | 1.0 mm |
| **中型** | **305** | **750 N** | **1.25 mm** |
| 重型 | 405 | 1250 N | 1.8 mm |

- **本项目要求**：墙面暗敷 **≥305 中型**；**地面及现浇板内必须 405 重型**
- ⚠️ 用 205 轻型省钱，回填或找平后管被压扁，日后抽不动线

## 1.6 强弱电施工细节（高标准）

## 1.7 网线

| 类别 | 带宽 | 10Gbps 距离 |
|---|---|---|
| 超五类 Cat5e | 100 MHz | 不支持（2.5G） |

- **每室一路网线汇聚到弱电箱**；客厅电视墙预留双芯皮线光缆（光纤入户）
- 弱电箱预留 AC 电源插座与散热空间
- ⚠️ 偷工点：Cat5e 冒充六类、铜包铝、串接不汇聚

## 1.8 打压与电气测试

**水压试验**（GB 50242-2002）：试验压力 = 工作压力 1.5 倍且 ≥0.6MPa。家装常用 **0.8MPa（冷水）/ 1.0MPa（热水）**，稳压 **30~60 分钟，压降 ≤0.05MPa**，逐个检查弯头与热熔接口无渗漏。**必须用水压，不能用气压**。

**电气测试**：相间及相对地**绝缘电阻 ≥0.5MΩ**（GB 55024-2022）；通电测试全部回路，标识回路名称。

**竣工资料**：水电隐蔽工程**竣工图 ＋ 照片 ＋ 打压记录 ＋ 绝缘记录**，交付时一并移交。

# 二、防水与回填

## 2.1 材料原则：墙刚地柔

| 部位 | 材料类型 | 代表与标准 |
|---|---|---|
| **墙面** | **刚性** | 水泥基渗透结晶型（GB 18445）、聚合物水泥防水砂浆（JC/T 984） |
| **地面 / 阴阳角 / 管根** | **柔性** | JS 聚合物水泥防水涂料（GB/T 23445）、聚氨酯（GB/T 19250） |
| 大砖墙面 | 瓷砖粘结层专用涂膜 | JC/T 2415 |

- ⚠️ **墙面用柔性防水会导致瓷砖脱落** —— 柔性膜表面致密光滑、没有咬合力，砖背胶挂不住，后期大面积空鼓脱落，这是业内最典型的坑。若墙面已做柔性，必须做拉毛 ＋ 界面剂处理

## 2.2 材料质量指标

| 标准 | 型号 | 关键指标 |
|---|---|---|
| GB/T 23445（JS） | Ⅰ型 | 拉伸强度 ≥1.20MPa；断裂伸长率 ≥200%；粘结强度 ≥0.5MPa；0.3MPa/30min 不透水 |
| GB/T 23445（JS） | **Ⅱ型** | 拉伸强度 ≥1.80MPa；断裂伸长率 ≥80%；粘结强度 ≥1.0MPa |
| GB/T 19250（聚氨酯） | Ⅰ型 | 拉伸 ≥2.0MPa；伸长 ≥500%；固含量 ≥85%；-35℃ 低温弯折无裂 |
| GB 18445（渗透结晶） | — | 抗渗压力、二次抗渗压力为核心 |

**本项目要求**：地面选 JS-Ⅱ型或聚氨酯；墙面选渗透结晶型或聚合物防水砂浆。

## 2.3 施工高标准

| 项 | 要求 |
|---|---|
| 基层 | 坚固、无浮灰浮砂；**2m 靠尺平整度 ≤3mm**；基面含水率符合产品要求 |
| 阴阳角 | 做 **R≥50mm 圆弧**或 45° 坡角 |
| 管根 / 地漏 / 阴角 | 先做**附加层 ＋ 玻纤网格增强**；穿楼板管根设**阻水台，高出成品地面 ≥20mm** |
| 涂刷 | **分 ≥2 遍（高标准 3 遍）**，先细部后大面积，**十字交叉**方向；表干后再刷下一遍（常温 4~8h）；每遍 0.5~1mm |
| 总厚度 | **地面 ≥1.5mm；墙面 ≥1.2mm**（JGJ 298-2013，最小厚度不低于设计值 90%） |
| 设防道数 | 卫生间 / 阳台为一级防水，**设防 ≥2 道**（GB 55030-2022）；设计工作年限 ≥25 年 |

**上返高度**（GB 55030-2022）

| 部位 | 上返高度 |
|---|---|
| **淋浴区** | **≥2000mm**（且不低于喷淋口） |
| 洗手盆处 | ≥1200mm |
| 卫生间其他墙面 | **≥300mm** |
| 厨房水槽处、洗衣机处 | ≥1200mm |
| 厨房 / 阳台其他墙面 | ≥300mm |

## 2.4 闭水试验

堵地漏 → 蓄水，**水深 ≥20mm**，**时长 24h（高标准 48h，不超过 48h）**。

**判定**：水位无明显下降；**楼下顶板、管根无渗漏、无水渍**。必须**楼下同步查看并拍照**存证。

## 2.5 下沉式卫生间回填

| 回填材料 | 评价 |
|---|---|
| 建筑垃圾 | ⚠️ **禁止**：重、有棱角会刺破防水层与管道、吸水、不密实、楼板荷载大。**行业通病，必须拒绝** |
| 陶粒 | 轻、圆滑不伤管；但吸水后增重，需砌砖格支撑 |
| **发泡水泥（泡沫混凝土）** | **当前高标准做法**：干密度 ≤600kg/m³（常用 300~500）、一体成型无缝、轻、不吸水，养护 ≥5 天 |

**两次防水（本项目强制）**

1. **回填前**：在结构层做第一道防水，并按 **1%~3% 坡度坡向二次排水口**
2. **回填并找平**（水泥砂浆 / 防水砂浆，厚 12~18cm）后，再做第二道面层防水

⚠️ 只做一次、或省掉找平层：水会在回填层闷泡，向墙外扩散，导致墙体空鼓、墙砖脱落、相邻地板起翘。

**回填层内必须做二次排水（暗地漏）**：设于沉箱最低点，接主排水管，兼作回填层积水泄水口 —— 下沉式 / 同层排水标配。

## 2.6 门槛与地漏（两个最易漏的点）

- **门口必须做挡水坎（止水坎）**：用防水砂浆或细石混凝土浇筑，**高 ≥20mm**，与地面防水层**连成整体**并向外延展；门槛石用防水砂浆**湿铺**，缝隙用硅酮密封胶收口；门槛处防水上返 ≥250mm
  ⚠️ 只做闭水、不设挡水坎，是门套发霉、外侧地板起翘的根源
- **地漏**（GB/T 27710-2020）：**水封深度 ≥50mm**；湿区必选**深水封**地漏（304 不锈钢或全铜）
  ⚠️ 浅水封（<50mm）易干涸返臭；机械自封（T 型 / 磁吸）不能替代水封

## 2.7 防水与回填验收清单

| 项 | 合格标准 | ✅ |
|---|---|---|
| 材料 | 有合格证与检测报告；**墙面刚性、地面柔性**，型号与部位匹配 | |
| 基层 | 平整 ≤3mm/2m；阴阳角圆弧 R≥50mm；管根有附加层 | |

# 三、泥瓦工程（瓷砖）

## 3.1 瓷砖选购硬指标

| 指标 | 标准 | 要求 |
|---|---|---|
| 吸水率 | GB/T 4100-2015 | **地面用瓷质砖（BIa）≤0.5%**，越低越致密 |
| 耐磨 | ISO 10545-7 | 家用 **PEI Ⅲ 级以上**（客厅地面建议 PEI Ⅳ） |
| 防滑 | DIN 51130 / GB/T 35153 | 卫生间地面 **≥R10**，淋浴区 **≥R11**；湿态摩擦系数 **≥0.60** |
| 破坏强度 | GB/T 4100 | 瓷质砖 ≥1300N；断裂模数 ≥35MPa |
| 厚度 | — | 750×1500 建议 **≥9mm**（主流 9~10.5mm），过薄易拱起 |
| 放射性 | GB 6566-2010 | **A 类**（使用范围不受限） |
| 3C 认证 | — | **仅吸水率 ≤0.5% 的瓷质砖强制带 CCC 标志**；可在认监委平台查证书编号 |

**柔光砖说明**：光泽度 15~25°，防滑优于亮光、无光污染，适合全屋通铺。缺点是表面有微孔隙、酱油咖啡需及时擦洗。**必须选"缎光釉 / 干粒抛"工艺**，劣质"柔抛"耐磨差、易渗污。

## 3.2 铺贴工艺（关键）

- 2022 年 9 月起住建部已叫停"饰面砖水泥砂浆粘贴工艺"
- 瓷砖胶执行 **JC/T 547-2017**：C1 ≥0.5MPa、C2 ≥1.0MPa；另有 T（抗滑移）、E（延长晾置）、S1/S2（柔性）附加等级
- **本项目要求：C2TE 或 C2TES1**；薄贴（胶层 3~5mm，齿形刮板梳刮），**满浆率 ≥90%**
- ⚠️ **750×1500 不能用传统水泥砂浆铺**：单块重 20~30kg、吸水率 ≤0.5% 表面致密，水泥砂浆只有机械咬合、无化学粘结；厚贴（10~20mm）收缩大，易空鼓脱落
- **背涂胶（背胶）**：刷在砖背、渗入微孔形成化学咬合并缓冲应力。**注意：背涂胶 ≠ 瓷砖胶**，两者是"砖背咬合 ＋ 胶层粘结"的组合，缺一不可

## 3.3 铺贴施工细节

| 项 | 标准 |
|---|---|
| 基层 | 2m 靠尺平整度 **≤3mm**，无空鼓、起砂 |
| 预排版 | **必须出排版图并经业主确认**；定起铺点；**非整砖 ≥1/3 砖宽**，小条砖赶至隐蔽处 |
| 对缝 | 卫生间、厨房墙地砖对缝（通缝） |
| 留缝 | 墙砖 2~3mm；地砖 2~3mm；**大砖 3~5mm**。必须留缝（热胀冷缩 ＋ 基层微变形） |
| 阳角 | 优选**海棠角**（水刀 45° 切，留 1~2mm 平边，现场拼角填环氧彩砂），比阳角条美观耐用。⚠️ 有崩边风险，需好砖 ＋ 好刀工 |
| 美缝时机 | 铺贴完成、**充分干燥后（≥7 天）**再施工 |
| 空鼓 | 国标 GB 50209-2010：地砖空鼓砖 ≤总数 5%。**本项目要求：墙砖 0 空鼓**、地砖单块空鼓面积 ≤0.04㎡ |

# 四、美缝

## 4.1 品类演进与选型

白水泥勾缝 → 单组分丙烯酸 → 真瓷胶（环氧树脂，硬脆、易黄）→ **环氧彩砂**（环氧 ＋ 石英砂，哑光、可调色、硬度高）→ **聚脲美缝**（天冬聚脲，耐黄变最强、韧性好、价高）

- **本项目要求**：**环氧彩砂（0 级耐黄变）**；**阳台、东晒 / 南晒房间建议用聚脲**
- ⚠️ 真瓷胶（亮面塑料感、45~85 元/支）温差大或地暖环境易开裂，浅色必黄

## 4.2 关键指标与标准

|---|---|
| **耐黄变** | **T/CBMF 166-2022 分 0~5 级，0 级最高**（168h 人工气候老化后无明显变色） |
| 三国标（写进合同） | **GB 18583-2008**（胶粘剂有害物质限量）、**GB 33372-2020**（胶粘剂 VOC 限量）、**T/CBMF 166-2022**（美缝剂） |

| 其他 | 耐磨、抗压强度、粘结强度、VOC / 游离甲醛合格 |

## 4.3 工艺：平缝 vs 凹缝

| 工艺 | 与砖面关系 | 外观 / 藏污 | 工费 |
|---|---|---|---|
| 压缝（凹缝） | 略低于砖面 | 立体，**易积灰变黑** | 低 |
| 压平缝 | 高低差 ≤0.2mm | 近齐平、易打理 | 中 |

- 阳角顺直、阴角饱满
- ⚠️ **黄变重灾区：阳台、东晒 / 南晒房间** —— 紫外线 ＋ 高温加速环氧树脂氧化，普通环氧必黄

## 5.1 石膏板

**GB/T 9775-2008**，代号：**P** 普通 / **S** 耐水 / **H** 耐火 / **SH** 耐水耐火；厚度 9.5 / 12 / 15mm。

| 厚度 | 纵向断裂荷载 | 横向断裂荷载 | 用途 |
|---|---|---|---|
| 9.5mm | ≥400N | ≥160N | 吊顶、隔墙基层 |
| 12mm | ≥520N | ≥200N | 隔墙、双层 |
| 15mm | ≥650N | ≥250N | 承重、隔音 |

- 耐水板：吸水率 ≤10%、表面吸水量 ≤160g/m²
- **本项目要求**：干区用普通纸面石膏板；**卫生间顶面用耐水石膏板（S）或硅酸钙板**
- ⚠️ 千年舟主业是板材，石膏板专业度不如龙牌（北新）、圣戈班、可耐福 —— 但 ENF 级已是合格线以上

## 5.2 轻钢龙骨

**GB/T 11981** 对**吊顶承载龙骨（主龙骨）**的规格要求：

| 类型 | 规格（宽×高×厚） |
|---|---|
| 承载龙骨（主） | 38×12×**1.0**；50×15×**1.2**；60×B×**1.2** |
| 覆面龙骨（副） | 50×19×**0.5**；60×27×0.6 |

- 材质要求：双面镀锌量 **≥100g/m²**，镀层 ≥14μm
- 挠度：承载龙骨静载 ≤4.0mm、覆面龙骨 ≤5.0mm
- **⚠️ 需要特别说明的一点**：市场上大量使用的**「卡式龙骨」（38 卡式主骨）**常见厚度 0.5~0.6mm，与国标**承载龙骨**（1.0mm）不是同一品类，数值不能直接比较

# 六、墙面涂装（重点）

## 6.1 乳胶漆的档次体系（"二合一 / 五合一"到底是什么）

- **"X 合一" = 功能数量叠加**（防霉 ＋ 抗碱 ＋ 耐洗刷 ＋ 净味 ＋ 抗甲醛…），属于**营销框架**，但确实对应功能多少
- 真正的档次看 4 条硬指标：
  1. **GB/T 9756《合成树脂乳液内墙涂料》等级**：优等品 ＞ 一等品 ＞ 合格品
  2. **GB 18582-2020 实测限值**（VOC、甲醛、苯系物）
  3. 是否 **"无添加"**（配方与生产中未人为添加苯、甲醛、VOC）
  4. 是否有 **A+、GREENGUARD 金级、芬兰 M1、TÜV** 等三方认证
- **"五合一优于二合一"成立**，但五合一内部分档：
  金装净味五合一 ＜ 竹炭净味五合一 ＜ 抗甲醛全效 ＜ 儿童漆 / 无添加全效

**本项目要求（书面标准写这一档）**：
> **无添加 ＋ 优等品 ＋ 抗甲醛/净味全效级**
> 对应参考：立邦「竹炭荷净全效 / 竹炭抗菌全效儿童漆 / 原生系列」；多乐士「森呼吸淳零无添加 / 至尊儿童漆」级别。
> ⚠️ 不接受"五合一"三个字就通过 —— 必须同时满足上述三项，并在合同中写明**具体系列名**。

## 6.2 关键性能与国标（GB/T 9756）

| 指标 | 合格品 | 一等品 | **优等品** |
|---|---|---|---|
| 对比率（白 / 浅色） | ≥0.90 | ≥0.93 | **≥0.95** |
| 耐洗刷性 | ≥350 次 | ≥1500 次 | **≥6000 次** |
| 耐碱性 24h | 无异常 | 无异常 | 无异常 |
| 表干时间 | ≤2h | ≤2h | ≤2h |

**本项目要求：优等品**（耐洗刷 ≥6000 次，是合格品的 17 倍）。

## 6.3 有害物质限值（GB 18582-2020）

内墙涂料：**VOC ≤80 g/L**；**游离甲醛 ≤50 mg/kg**；苯系物总和 ≤100 mg/kg；可溶性铅 ≤90、镉 ≤75、铬 / 汞各 ≤60 mg/kg；APEO ≤1000 mg/kg。

**要求提供**：该型号的型式检验报告，核对上述数值。

## 6.4 底漆（不能省）

**执行 JG/T 210《建筑内外墙用底漆》**：耐碱 24h 无异常；附着力 ≤2 级；透水性 ≤0.5mL；抗泛碱 48h 无异常。

- 作用：封闭抗碱、提高面漆附着力、节省面漆
- **新墙、旧墙翻新、返碱起粉基面**尤其必须
- ⚠️ 省底漆是常见偷工项

## 6.5 遍数、兑水与用量

| 项 | 标准 |
|---|---|
| 遍数 | **底漆 1 遍 ＋ 面漆 2 遍**（高标准可 3 遍面漆，提升均匀度与耐洗刷） |
| 兑水 | 立邦 / 多乐士多为 **≤20%**（部分系列 ≤5%）；⚠️ **严禁多兑**，遮盖力与耐洗刷会骤降 |
| 用量 | 面漆约 11~14 ㎡/L·遍；底漆约 11~12 ㎡/L |
| 间隔 | 表干 1~2h；**重涂间隔 2~4h**（手摸不粘、指压不陷） |
| 成品保护 | 涂装完成后保护成品；**面板灯具安装前完成开荒** |

## 6.6 腻子（关键项）

**JG/T 298-2010《建筑室内用腻子》**

| 类型 | 粘结强度 | 耐水性 |
|---|---|---|
| Y 型（一般型） | ＞0.30 MPa | 无耐水要求 |
| **N 型（耐水型）** | **＞0.50 MPa，浸水后 ＞0.30 MPa** | **48h 耐水** |
| R 型（柔韧型） | ＞0.40 MPa | — |

**本项目要求**：

1. **必须 N 型耐水腻子**，且为**成品干粉腻子（加水即用）**
2. ⚠️ **现场配胶是红线**：107 胶（聚乙烯醇缩甲醛）**国家已禁用**，游离甲醛高；801 / 108 胶只是改良版，仍会长期缓慢释放甲醛
3. 做法：高强耐水腻子**批刮 2~3 遍**（每遍薄刮 0.5~1mm），干后 **240 目砂纸**打磨，**强光手电侧照**检查，无划痕、无坑洼

## 6.7 基层与防裂

- **界面剂 / 墙固**：选**乳液型**（水性墙面固化剂）；⚠️ 胶水型 / 108 类甲醛风险高
- **挂网**：新砌墙、新旧墙接缝、开槽处、石膏板接缝、线盒处**必须局部挂网**；全屋挂网属增项，可按预算选

| 项 | 要求 |
|---|---|
| 基层 | 平整度 **≤2mm/2m**；含水率 **<10%**；pH **<10**；打磨 **300 目以上** |
| 工艺 | 抗碱底漆 1 遍 → 艺术漆多道 → **罩面清漆 / 罩面漆 1~2 遍**（防水防污，**不可省**） |
| 品类 | 雅晶石、微水泥（1~3mm）、稻草漆、肌理漆等 |
| 色差控制 | ⚠️ **强制同批号、留备用料**（艺术漆最大的问题是批号色差） |
| 参考品牌 | 进口：novacolor、菲玛、卡百利、Cafonci；国产：嘉宝莉（珈蓝邸）、三棵树、立邦魔术漆 |

**常见问题**：色差、开裂、泛碱、接缝不齐 —— 验收时重点查这 4 项。

# 八、自装材料 vs 装修公司供材（为什么自购更好）

## 8.1 行业机制：专供款 / 工程款

- **同品牌常分两条产线**：门店的「零售款 / 柜台款」与工程的「**专供款 / 工程款**」。外观 logo 相同，**型号只差后缀**（如"优品系列""工程专供"），采购成本可低至零售的一半
- 零售款可在官网、旗舰店、400 电话查到；**专供款往往查不到**
- **"大品牌 ＋ 低配置"是最常见手法**：用马可波罗、科勒这类牌子取信，用低系列降本 —— 吸水率、耐磨、釉面、五金厚度、质保全线缩水

## 8.2 加价率常识

- **主材常见加价 20%~50%**；瓷砖、地板这类工装 / 家装差价可达约 40%
- 整体加价 20%~30% 很普遍

## 8.3 自购的优势（具体到能买到什么）

| 项 | 装修公司低配 | 自购同预算可得 |
|---|---|---|
| 瓷砖胶 | 水泥净浆或普通胶 | **C2TE 级瓷砖胶** |
| 石英石台面 | 含量不明 / 人造石 | **93~95% 石英含量** |
| 合页 | 2 个 | **3 个不锈钢加厚** |
| 角阀 | 锌合金 | **全铜 ＋ 陶瓷阀芯** |
| 电线 | ZR-BV | **WDZ-BYJR-105** |
| 售后 | 商家口头承诺 | **品牌全国联保** |
| 搭配 | 捆绑套餐 | **自由搭配**，不被套餐限制 |

## 8.4 自购的风险（必须知道）

1. **责任划分**：材料色差、批号不一致，装修公司不担责；材料质量与施工质量难界定，容易扯皮
2. **售后**：材料商与施工方互相推诿；小商家跑路无保障
3. **假货 / 调包**、批次色差
4. **损耗算不准**：大砖损耗 3%~8%，补货不及时会停工

## 8.5 可执行的辨别方法

1. **合同写死**：品牌 ＋**完整型号（含后缀字母/数字）**＋ 执行标准号 ＋ 等级 ＋ 规格 ＋ 数量 ＋ 批次，**拒绝"同档次""同款"话术**
2. **"三码合一"**：外包装条形码、合格证编号、**防伪溯源码**三者对应，扫码验真
3. **查 3C**：瓷质砖（吸水率 ≤0.5%）必须有 CCC，可在**认监委平台查证书编号**
4. **看包装喷码**：激光喷码含生产日期 / 产线 / 质检员代码；缺失者多为代工专供
5. **官网比型号**：拿型号去品牌官网或旗舰店核对是否为在售零售款
6. **验瓷砖**：核对吸水率标注、同批号、称重、平整度
7. **留证据**：样品 ＋ 发票 ＋ 检测报告；隐蔽工程留影像
