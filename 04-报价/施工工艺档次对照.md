# 主要施工工艺档次对照

> 说明：供报价方了解业主对施工工艺的认知，便于沟通。
>
> - **低配做法**：市面上低价报价常见的做法，**业主不接受** —— 这一列同时也是验收时的"盯防清单"。
> - **标准做法**：业主的**基本要求（最低线）**，报价不得低于此档。
> - **高配做法**：可加分项，不作强制。
> - **建议**：业主倾向于选哪一档，以及取舍理由 —— **不追求最贵，够标准、不出后患即可**。
> - **说明**：两档做法的差别，以及为什么值得按标准档做。

| 工序 | 低配做法 | 标准做法 | 高配做法 | 建议 | 说明 |
|---|---|---|---|---|---|
| 界面剂 / 墙固 | 801 胶、108 胶兑水滚涂 | 乳液型墙固（立邦 / 圣戈班伟伯） | 进口界面剂（马贝） | **标准档**。乳液型与 801 胶差价很小，环保性却差一个层级，不要为省钱降级 | 801、108 胶含游离甲醛且封闭性差；乳液型是"胶水"到"界面剂"的升级 |
| 墙面找平 | 直接用腻子厚批找平 | 底层石膏找平（占比 >70%）+ 腻子 | 冲筋找平（垂平工艺） | **标准档 + 局部冲筋**。本户型横梁柱多，整体冲筋贵；只需在有柜体、门套的位置冲筋 | 腻子厚批必开裂；冲筋能让墙面垂平，柜体贴合更好 |
| 腻子 | 双飞粉 / 821 腻子 + 现场兑胶 | 成品耐水腻子（N 型）**直接加水** | 成品腻子 + 全屋强光打磨验收 | **标准档**。不要为省几百块用双飞粉兑胶，这是室内甲醛的主要来源 | 现场兑胶等于把甲醛批进墙；821 腻子已被国家限制使用、不耐水易起皮 |
| 防水涂刷 | 只刷 1 遍、墙面上返 300mm | 墙面渗透型 2 遍（上返 ≥1.8m）+ 地面柔性 2~3 遍 | 加做基层处理剂 + 防水刮尺 | **标准档**。全屋防水材料费通常几百到一千元，是**最不该省**的一项 | 一遍刷厚等于没刷；高度不够隔壁墙面返潮发霉。这道省的钱，返工要花十倍 |
| 闭水试验 | 不做，或只做几小时 | 蓄水 24~48 小时，与楼下住户共同确认 | 48 小时 + 二次复检 + 影像留档 | **标准档**。零材料成本，只看施工方肯不肯做 | 不做闭水，渗漏往往住进去半年后才暴露，那时已无法处理 |
| 卫生间回填 | 建筑垃圾、砖渣回填 | 轻质回填材料（发泡水泥 / 轻质回填王） | 发泡水泥整体浇筑 | **标准档**。轻质回填比砖渣贵得有限，但决定十年后是否沉降 | 砖渣重、易沉降、会拉裂防水层。隐蔽工程里最不能省的一项 |
| 电线 | ZR-BV 阻燃 PVC 线 | 无卤低烟阻燃（WDZ）交联聚乙烯线 | 全国一线（远东、上上、宝胜） | **标准档**，可考虑升级到全国一线。WDZ 比 ZR-BV 单价高约一到两成，建议升级 | WDZ 燃烧时毒烟少、耐温 105℃。家装升级成本不高，属于花小钱办大事 |
| 给水管 | 全屋按 S3.2 冷水管配 | 热水段 S2.5（dn20×3.4）+ 冷水段 S3.2 | 伟星（含免费试压、管路图存档） | **标准档**。热水段 S2.5 是硬线，不能谈 | 同一根 dn20 壁厚差 0.6mm、成本差两成，是最隐蔽的缩水方式 |
| 穿线管 | 205 轻型线管 | 305 中型及以上、可冷弯 | 405 重型（大功率 / 主干） | **标准档**。305 中型与 205 轻型差价极小，没必要省 | 轻型管上墙易压扁，后期换线抽不动，等于管路一次性 |
| 电路回路 | 全屋串成一两个回路 | 回路独立 + 零线入户，空调 / 厨卫单独回路 | 每室独立 + 全屋零线 + 回路图存档 | **标准档**。回路数按实际用电需求定，但不接受"全屋两个回路" | 串接回路一断电全屋黑，大功率设备共用回路有跳闸风险 |
| 水路走向 | 水管走地 | **厨卫水电集中走顶** | 全屋走顶 + 管路图存档 | **标准档，强烈建议**。走顶比走地多的人工有限，后期差别很大 | 走顶漏水先漏自己家、便于检修；走地漏水要先砸地砖，还可能泡到楼下 |
| 下水管 | 普通 PVC-U（含铅稳定剂） | PVC-U **无铅** + 隔音棉包覆 | 同层排水 + 静音管 | **标准档**。包隔音棉成本很低、效果明显，属于小钱办大事 | 无铅配方更安全；隔音棉能明显降低楼上冲水声 |
| 隐蔽工程存档 | 不拍照，直接封槽 | 封槽前拍照 + 出管线走向图 | 全景影像 + 实测尺寸标注 | **标准档**。零成本，业主验收必查，缺此项不予验收 | 没图，后期装柜子、挂画打孔必打穿管，损失只能自担 |
| 瓷砖铺贴 | 水泥净浆 + 现场掺胶 | 瓷砖胶（C1 / C2 级）+ 背涂胶 | 全屋薄贴 + 基层拉毛 | **标准档**。750×1500 上墙必须 C2 级 + 背涂，不接受水泥净浆 | 大规格砖、低吸水率砖用净浆必空鼓 |
| 瓷砖排版 | 现场随手铺 | 先出排版图，定起铺点与收边位置 | 全屋通铺排版 + 对缝方案 | **标准档**。排版图是零成本的，开工前必须拿到并经业主确认 | 不排版，门口或过道容易出现小条砖，是返工的主要原因之一 |
| 阳角处理 | 砖边直碰 | 45° 倒角（留 1mm 钝边）或阳角条 | 水刀切割海豚角 | **标准档**。倒角费需单独报价，先谈定单价与数量再施工 | 直碰易崩瓷、边角锋利伤手 |
| 美缝 | 普通填缝剂 / 真瓷胶 | 环氧彩砂 + 平缝工艺 + 0 级耐黄变 | 进口环氧彩砂（马贝 / 西卡） | **标准档**。差价主要在工艺（平缝 vs 凹缝）与耐黄变等级，品牌其次 | 真瓷胶是亮面、易黄变。重点看工艺与耐黄变等级，不是看品牌 |
| 吊顶副龙骨 | 副龙骨间距 600mm | 间距 300~400mm，壁厚 ≥0.45mm | 加密龙骨 + 全屋满吊 | **标准档**。龙骨加密几乎不加材料钱、只多人工，是性价比最高的一项 | 间距过大顶面会下垂、踩踏会变形 |
| 石膏板接缝 | 拼缝处直接批腻子 | 嵌缝石膏 + 贴耐碱玻纤网格布 | 双层石膏板 | **标准档**。网格布成本极低，不做的话两年内必裂 | 只批腻子，季节交替后必然开裂，是吊顶最常见的售后问题 |
| 吊顶转角 | 两块板拼接 | 整板 L 形切割 | 整板 + 加固角码 | **标准档**。整板切割只影响下料方式，不额外加钱 | 转角处拼接必裂，L 形切割是吊顶防裂的标准做法 |
| 腻子打磨 | 打磨一遍了事 | 逐遍打磨，240~320 目 + 手电侧照检查 | 全屋强光验收 + 二次修补 | **标准档**。打磨是人工活，要把**遍数与验收方式写进合同** | 打磨不到位，面漆会显出波浪纹，灯光下一照就露馅 |
| 乳胶漆 | 面漆 1 遍 | 底漆 1 遍 + 面漆 2 遍 | 进口漆 + 无气喷涂 | **标准档**。遍数写进合同，不接受"面漆一遍" | 减少遍数是最常见的偷工，验收时看不出，两三年后掉粉或发花 |
| 中央空调风口 / 回光槽 | 不做加固，风口随意开 | 出风口加固 + 回光槽按灯带尺寸预留 | 风口边框定制 + 藏灯设计 | **标准档，高配按预算选**。风口边框定制属加分项，可后期再做 | 风口不加固会变形下坠；本项目"有主灯 + 回光槽"为硬性要求 |
| 成品保护 | 不保护或只保护地面 | 门窗、公共区域、下水口**全保护** | 全屋覆板保护 + 分阶段验收 | **标准档**。公共区域必须保护，否则物业罚款容易扯皮 | 后期划伤、堵管都算业主成本。保护做得越早，扯皮越少 |

---

> 本表所列工艺，为业主对施工的最低标准。报价方如以"常规做法""行业通用"等表述替代具体工艺参数，业主有权不予认可。
