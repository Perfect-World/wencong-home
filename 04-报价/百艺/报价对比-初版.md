> 对比对象
> - 自控价：`01-需求与预算/装修控价表.xlsx`

> - 百艺主材：`04-报价/百艺/主材最新报价.xlsx`（直接费 96,288.2）

## 三、最值得关注的 6 个差异

### 1. 定制柜：自控价贵 1.68 万，但不可直接比
- 百艺 499 元/㎡（欧松板柜体+柜门，ENF 级，悍高一段力五金）
- 自控价 衣柜 1,000、客厅柜 1,300、橱柜 11,000/套（艾高）
- 差 16,829 元。**要么自控价按 499 重算，要么让百艺按艾高同档重新报价**，否则总额永远对不上。

### 2. 墙面：工艺不同，差 1 万
- 百艺：乳胶漆 38 元/㎡ × 373.4㎡ = 14,189
- 自控价：腻子 + 艺术漆（雅晶石）200㎡ = 24,350
- 百艺报价里**没有艺术漆**。如果你要做艺术漆，要在百艺基础上另加 8,000~12,000，这一项会把差额拉到 3 万以上。

### 3. 水电：单价和面积都高
- 百艺：人工 52 + 材料 72 = **124 元/㎡ × 152㎡ = 19,448**
- 自控价：材料 60 + 人工 35 = **95 元/㎡ × 135㎡ = 12,825**
- 面积差 17㎡（152 vs 135），单价差 29 元/㎡，两头叠加差 6,623。

### 4. 瓦工：墙面面积口径不一致
- 百艺墙面贴砖 **81.6㎡**，自控价墙面 **62㎡**，差 19.6㎡（约 1,760 元只是面积差）
- 地砖 105/㎡ 是否含薄贴辅料？百艺另收瓷砖胶 28/㎡，自控价把成品砂浆、瓷砖胶、冲筋都单列了 —— **两边算法不同，需要统一**。

### 5. 管理费 14,743：自控价里没有这一项
- 基础 8% + 主材 8%，两份都收。按行业惯例管理费一般 5%~8%，且**按基础工程收一次**较多。
- 这一项建议直接谈，能省 5,000~7,000。

### 6. 综合杂费 6,352：自控价的盲区
材料搬运 1,672 + 垃圾清运 1,500 + 成品保护 800 + 灯具安装 680 + 墙固 800 + 全房挂网 900。
其中**墙固 800、挂网 900** 属于工艺项，不算坑，但自控价确实漏了，需要补进预算。

## 五、自控价自身要修的问题

1. **总控「水电」显示 8,100，但硬装小计是 12,825**（漏了人工 4,725），导致分类合计 134,844 ≠ 硬装总计 139,569。
2. 自控价**没有管理费**，与百艺对比时会天然"显得便宜"1.47 万。
3. 自控价没有：材料搬运 1,672、成品保护 800、墙固 800、挂网 900、灯具安装 680、瓷砖加工 500，另有门洞修补 450、夹角找平 680（已并入百艺瓦工行）。前六项合计约 5,350。
4. 建筑面积用的是 135㎡，百艺按 152㎡ 计（含墙体/公摊口径不同），需确认哪个是计价面积。

## 六、折后 18 万怎么看

百艺口头"折后约 18 万"，对应降价 **20,247 元（约 10.1%，合 89.9 折）**。这个数字要分三层看：

### 第 1 层：纯数字比（最容易误判）

| | 金额 |
|---|---:|
| 百艺折后 | 180,000 |
| 自控价 硬装+主材 | 176,719 |
| 差额 | +3,281（百艺高 **1.9%**） |

看着几乎持平，但**自控价里没有管理费、没有搬运/保护/墙固/挂网/加工费**，这两项在百艺那边是实打实收了的。

### 第 2 层：同口径比（自控价补齐管理费和杂费）

自控价 176,719 × 1.08（管理费）+ 5,350（杂费）= **约 196,206**

| | 金额 |
|---|---:|
| 百艺折后 | 180,000 |
| 自控价（补管理费+杂费） | 196,206 |
| 差额 | **百艺便宜 16,206（-8.3%）** |

这一层看，百艺折后**确实便宜**，约 1.6 万。

### 第 3 层：同工艺比（都做艺术漆 + 同档定制柜）

百艺的 18 万是**乳胶漆 + 499/㎡ 欧松板柜**；自控价是**艺术漆 + 1,000~1,300/㎡ 柜**。

| | 金额 |
|---|---:|
| 百艺折后 + 艺术漆 10,161 + 柜体升级 16,829 | **约 207,000** |
| 自控价（含艺术漆、同档柜、补管理费杂费） | 196,206 |
| 差额 | **百艺高 10,794（+5.5%）** |

如果你要的效果就是自控价里的艺术漆和中高端定制柜，**百艺折后实际会走到 20.7 万左右**，不是 18 万。

### 所以怎么判断

- **接受乳胶漆 + 499 柜**：百艺折后 18 万划算，比自控价口径便宜约 1.6 万。
- **坚持艺术漆 + 1,000+/㎡ 柜**：百艺折后要到 20.7 万，比自控价贵约 1.1 万。
- 18 万只是**口头约数**，必须落到书面：折后价对应的项目清单、面积、品牌、工艺要一字不差地写进合同附件。

### 折扣必须书面确认的 5 件事

1. **折后价是否含管理费**（原价里基础 8% + 主材 8% 共 14,743）
2. **折后价是否含保洁 1,216、税金**
3. **折扣是否覆盖"按实结算"项**（钻孔、防护网、风管机配套、全开槽等）—— 通常不覆盖，等于打折后还会再加钱
4. **减项怎么退**：条款写"减项超 10% 只退 50%"，打折后是按原价扣还是按折后价扣？要写清
5. **折扣与赠送/升级的先后**：先打折再升级，还是升级后打折，差几千

## 七、下一步建议

1. **先统一面积**：确认计价面积到底是 135 还是 152㎡，这直接影响水电、搬运、保洁、开关插座四项。
2. **让百艺补三项报价**：艺术漆、定制柜按自控价档次（1,000~1,300/㎡）、洁具品牌型号明细。
3. **把待定项锁死**：机械钻孔、防护网、风管机配套、全开槽 7 项必须给数量或封顶价。
4. **谈管理费**：目标从 8%+8% 降到 5%（或只收基础一份），预期再省 3,000~5,000。
5. **把折扣写进合同**：18 万对应哪些项目、面积、品牌、是否含管理费/保洁/税、按实结算项是否参与折扣，全部落到附件。
6. **统一工艺再比总额**：现在的 176,719 vs 200,247 有 2 万多是口径差；折后 18 万同样要和"同工艺、同面积、同品牌"比才有意义。
