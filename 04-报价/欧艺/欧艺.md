## 品牌选择建议

| 品类 | 选择 | 备注 |
|---|---|---|
| 木工板材（打底 / 造型） | 千年舟 | 杭州品牌，ENF 级环保等级最高；15 / 12 / 9mm 三种厚度都列了 |
| 定制柜板材 | 兔宝宝（生态板） | 上市板材龙头，ENF 级、渠道最广；千年舟同档可备选。欧艺写「生态板柜体 ＋ 欧松板柜门，背板 9mm」——**背板 9mm 高于常见的 5mm，是加分项** |
| 纸面石膏板 | 千年舟 | 唯一选项，ENF 级；但千年舟主业是板材，**石膏板专业度不如龙牌、圣戈班**，建议争取更换 |
| 轻钢龙骨 | 千年舟（主 0.55mm / 副 0.45mm） | 规格写得比多数家清楚；**主龙骨 0.55mm 高于行业常见的 0.5mm**，是加分项。需再写明副龙骨间距 300~400mm |
| 腻子 / 嵌缝石膏 / 墙固 | 立邦 | 立邦成品体系统一；须确认是**耐水型（N 型）成品腻子**、直接加水，不得现场掺 801 胶 |
| 乳胶漆 | 立邦（要求升级系列） | 「净味 120」是立邦的**入门系列**，建议升级到净味全效或竹炭系列；底漆已是全能抗碱底漆，合格 |
| 电线 | 武汉二厂（飞鹤牌） | 欧艺两处写法冲突：材料表写「美国惠普（美国 / 深圳）」，施工条款写「武汉二厂」。**武汉二厂 ＝ 飞鹤牌**，是湖北本地一线，与弱电所用飞鹤为同一厂家，可信；「美国惠普」需核实真实厂家。建议按武汉二厂签约 |
| 线管 / 下水管 | 加拿大皇家（须核实） | 「加拿大皇家（加拿大 / 天津）」需核实国内实际生产厂家；规格齐全（线管 [16/20]、下水管 50/75/110）。PVC 线管须为 **305 中型及以上**，不得用 205 轻型 |
| 给水管 | 日丰（PP-R 抗菌管） | 欧艺两处写法冲突：材料表写「德国卡文（德国 / 越南）dn20/25」，施工条款写「日丰」。**日丰为国内一线、50 年双质保**，建议按日丰签；「德国卡文」需核实。热水段须写明 **S2.5（dn20×3.4）** |
| 网线 | 秋叶原（6 类，须确认屏蔽） | 材料表写「秋叶原 6 类」，施工条款写「六类**双屏蔽**」——两处不一致，须确认是否含屏蔽 |
| 水泥 | 华新（32.5） | 华新为湖北龙头、全国前列。32.5 用于砌筑抹灰没问题；但 **750×1500 大砖用传统水泥砂浆铺贴有风险，建议改用瓷砖胶（C1 / C2 级）薄贴** |
