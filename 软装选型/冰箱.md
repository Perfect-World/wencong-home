## 一、需求口径

- **双系统双循环**：冷藏、冷冻各一套独立蒸发器 + 独立风机，物理隔绝串味
- **法式门**
- **白 / 灰** 面板
- **独立摆放，不嵌入**（外观看得见，颜色和面板要跟周围环境协调）
- **制冰可有可无**
- 预算参考：6000 元左右

## 二、阶段性结论

## 四、逐台档案

### 1. 海尔 大海鲸 620（当前首选）

- 型号：BCD-620WGHFD1BRBU1，京东专供，与云溪 Max630 同机
- 布局：法式四门；冷藏四个独立抽屉（2 鲜活保湿 + 1 三档变温 + 1 熟食区），开半扇门即可抽；冷冻最下层抽屉因压缩机舱重排而加宽，可平放羊腿、排骨
- 保鲜：全空间保鲜、阻氧干湿分储、冷冻智能恒温 2.0（波动约 0.7℃）、-30℃ 深冷
- 净化：冷藏 + 冷冻双 EPP 超净，熟食区另加黑金净化（四台中唯一）
- 制冰：仅随附手动塑料冰格，无自动制冰系统——不用制冰的人反而省钱
- 价格：京东 7516.24 / 抖音 6599 / 全网最低 5300
- 短板：905mm 宽，需预留约 913mm；深色系，与浅色墙面搭配要确认

## 五、横向对比要点

### 5.1 同平台 / 同集团关系（避免重复比价）

- **海尔系**：卡萨帝（高端）、海尔（主力）、统帅（入门）。同集团共用产线、售后体系，技术投放有代差
- **海信系**：海信、容声、科龙。海信 560 与容声 563 尺寸完全相同（860×598.5×1925），是同一箱体系列
- **大海鲸 620 = 云溪 Max630**：同机不同名，京东 vs 天猫/抖音，深色 vs 浅色
- **容声 510 / 海信 509Pro**：同箱体姊妹机

### 5.3 噪音（标称值，非实测）

- 31dB：大海鲸、海信 560、容声 563、麦浪、云溪
- 33dB：容声机皇 510
- 34–35dB：美的熊墩墩、卡萨帝 520（官网确认 35dB）
- 网络曾出现大海鲸 37dB 的说法，已核实为 31dB
- 说明：均为厂商标称值，无第三方实测；实际受摆放、共振、压缩机转速影响

### 5.4 100L 差在哪（大海鲸 620 vs 卡萨帝 520）

- **+39L 冷藏** ≈ 多一整层搁架（约 10cm 高）
- **+28L 冷冻** ≈ 多三分之一到大半个抽屉
- **+33L 独立变温** ≈ 20 瓶饮料或 4–5 斤肉
- 结构差异：大海鲸冷藏四抽屉可分类，卡萨帝为 3 搁架 + 果菜盒
- 换算参考：每人约需 100–150L，100L ≈ 一个人的储备量

### 5.5 净化方案梯队

1. 海尔三重（冷藏 EPP + 冷冻 EPP + 熟食区黑金）
2. 容声 IDP 双净 2.0（冷藏 + 冷冻双区主动）
3. 美的 PST+7.0 双区 + UV
4. 海信 DBD（仅冷藏主动）+ AI 巡航净味（检测型，不等于除菌更强）
5. 卡萨帝 冷藏动态除菌 + 冷冻 A·SPE

### 5.6 双系统怎么验

- 单系统单循环：1 蒸发器 1 风道
- 单系统双循环（常被叫「双循环」）：1 蒸发器 + 2 风道 + 风门，只能减轻串味
- **双系统双循环**：2 蒸发器 + 2 路独立风道，物理隔离
- 话术：问客服「冷藏和冷冻是不是各有一个独立蒸发器」，只答「双循环」不算

## 六、选购原则

1. **同价选配置，不默认选高端品牌**。高端品牌在同价位给的是入门款，配置必然更低；品牌溢价买的是面板、服务和设计，不是更耐用或更长保修
2. **冰箱独立摆放且可见时，外观权重应高于参数表**
3. **不为不需要的功能付费**（如制冰）
4. **尺寸先量再选**：宽需预留 +8mm 左右，深 594/598.5 都能做 60cm 平嵌，高度 1925（美的 1910）
5. **散热**：四台均为底部/前置散热，可贴柜；但插座不能留在正后方，背后仍需散热空间
6. **搬运**：1925mm 高、116–133kg，法式四门通常需拆包装进电梯
7. **渠道风险**：5300 买京东 7998 的机器，必须确认是否国补机、能否开正规发票、是否官方授权、安装是否含、是否展示机/渠道机。卡萨帝七星服务依赖授权渠道和官方激活
