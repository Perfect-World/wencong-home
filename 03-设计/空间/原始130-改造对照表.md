## 3. 结论

1. **原始 130 是「三卧 + 书房 + 衣帽间 + 厨房」的分离格局**：客厅 18.13、卧室 11.40/7.80/6.38、书房 6.60、衣帽间 3.91、厨房 4.32。
2. **改造方案是大开间 + 三卧三卫**：客餐厅 73.78 是把原始客厅、书房、厨房、入户及部分卧室打开后的**开间面积**，不是原始客厅 18.13 的放大；不能把 73.78 当作原始客厅尺寸使用。
3. 改造的南次卧 11.99、北次卧 8.73 与原始 11.40、7.80 接近；主卧套 27.34 很可能是原始 6.38 卧室 + 书房 + 衣帽间 + 主卫合并（推测，待叠图）。
4. 改造的厨房从 4.52 扩大到 6.27（1990×3150），可能是并入原设备平台/入户花园；需用原始墙位确认可拆范围。
5. 原始图上的黑墙是建施的结构墙/剪力墙候选；改造方案拆墙前必须逐段与原始图核对，尤其是南次卧+南次卫套房、主卧套、开放式厨房三处。

## 4. 必须注意的面积口径问题

改造图（家具图-2 / 空间.md）里多处**标注面积与尺寸乘积不一致**，差额较大，先列出来，不要直接拿去做预算或施工：

| 空间 | 标注面积 | 尺寸乘积 | 差额 |
|---|---:|---:|---:|
| 客餐厅 | 73.78㎡ | 8955×6635 = 59.4㎡ | +14.38㎡ |
| 南次卧 | 11.99㎡ | 2976×3440 = 10.24㎡ | +1.75㎡ |
| 北次卧 | 8.73㎡ | 2990×2560 = 7.65㎡ | +1.08㎡ |
| 南次卫 | 5.05㎡ | 1880×1440 = 2.71㎡ | +2.34㎡ |
| 主卫 | 4.57㎡ | 1530×2230 = 3.41㎡ | +1.16㎡ |
| 北次卫 | 2.92㎡ | 1770×1650 = 2.92㎡ | 0（对得上） |

可能原因：面积含墙体/相邻过道/阳台，或尺寸是净尺寸、面积是建筑面积，或标注本身有误。**建议让设计师确认每个空间的面积口径**，尤其是南次卫 5.05 与 1880×1440 的 2.34㎡ 差额。

原始 130 的房间面积与反推尺寸基本自洽（7.80 = 2600×3000 完全对上），但原始图只标了部分房间净面积，卫生间、餐厅、过道、阳台/花池未标，**58.54㎡ 不是本户套内总面积**。
