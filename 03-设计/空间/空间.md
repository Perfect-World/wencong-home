## 二、总体格局

### 2.1 面宽与进深

- 户内结构面宽 **16.51 m**，左侧进深 **9.765 m**，右侧进深 **7.801 m**，南侧有一步退台/凹口。
- 南向面宽：客餐厅约 **8.955 m** 连续窗带 + 南次卧约 **2.975 m** 面宽（窗洞约 2.375 m），是全屋采光的主轴。
- 西侧为主卧套，北侧为厨房/北次卧/北次卫，东侧为入户与储物间。

### 2.2 功能分区

| 区域 | 位置（图面方向） | 主要空间 |
|---|---|---|
| 南侧公共区 | 南（图上方） | 客餐厅（阳台 + 客厅 + 书房 + 过道）、南次卧（含南次卫套房） |
| 西侧主卧套 | 西（图右侧） | 主卧睡眠区、主卫（西南角）、衣帽间（西北角） |
| 北侧服务区 | 北（图下方） | 餐厅、厨房、北次卧、北次卫 |
| 东侧入户区 | 东（图左侧） | 入户门斗、玄关/过道、电梯厅/储物间 |

### 2.3 动线

- **入户**：东侧门斗进入玄关/过道；过道两侧分别是客厅（南）和餐厅（北），入户不经过餐厅；鞋柜/换鞋凳放在电梯厅，不占门斗。
- **公共区**：客餐厅是全屋的交通枢纽；南次卧、主卧、北次卧、北次卫的门开向它或它北侧的短走道；南次卫改为南次卧套内，不再开向公共区。
- **主卧套**：主卧门开向客餐厅西端，主卫在套内西南角，衣帽间在套内西北角，形成“睡眠区 + 主卫 + 衣帽间”的完整套房。
- **服务区**：厨房全开放、无门，与餐厅连成一体；北次卫夹在厨房与北次卧之间，服务北次卧和公共区。

### 2.4 结构墙与柱

墙体定位图中灰色填充为主要剪力墙/柱；拆改前以灰色填充为准，并现场确认，不能把白色轻质墙当承重墙：

| 位置 | 尺寸/厚度 | 影响 |
|---|---|---|
| 南次卧与客餐厅之间 | 220 厚，长约 3.67 m（2165+1504） | 南次卧西墙不能拆，门位/衣柜受限制 |
| 客餐厅西南角（主卧一侧） | 810×840 柱，带 400/580 凸出 | 客餐厅西南角有凸柱，沙发/柜体要避让 |
| 主卧与北次卧之间 | 220 厚，长约 2.0 m | 两卧室之间不能打通 |
| 北次卧与北次卫之间 | 220 厚，长约 2.41 m | 北次卫门位/蹲便器布置受限制 |
| 南次卫四周 | 局部 240 / 155 | 南次卫为小开间；套房门改到南次卧北墙，需确认墙属性 |
| 厨房西南角烟道 | 460×520 | 不可拆改；冰箱柜/台面避让，保留包管/检修口 |
| 南侧外墙 | 窗间墙/窗下墙 | 南向连续窗带，窗间墙不可随意拆 |

> 横梁多、有浇铸柱；非必要不吊顶，中央空调走边吊。梁位和梁高见后文墙窗梁表。

### 2.5 采光与通风

- **南向**：客餐厅约 8.76 m 通长窗 + 南次卧窗，是全屋主要采光面。
- **西向**：主卫、衣帽间有西向窗；主卧的主采光是南向窗（W-S3），窗外无设备平台；西墙以主卫/衣帽间和衣柜为主，不是直接西窗。下午有西晒，主卫/衣帽间和主卧南窗需遮阳。
- **北向**：厨房、北次卧、北次卫有北向窗，光线稳定；北次卫按明卫考虑。
- **东侧**：南次卫有一扇东向**半窗**（窗台 TH 1620 / 窗高 CH 1240），朝东侧凹槽/储物间，采光有限，按**半明卫**处理；排风、防水仍是重点。
- **通风**：南窗—北窗可形成穿堂风，但客餐厅进深大（约 6.7 m），自然通风，中央空调。
- **设备**：中央空调外机放**储物间南侧**；室外机、冷媒管、冷凝水、新风取风口的位置在平面阶段定路由。

## 三、逐空间描述

### 3.1 客餐厅（约 73.78 ㎡）

- **位置**：全屋中心，南接通长窗/阳台，北接厨房/北次卧/北次卫，东接玄关/过道，西接主卧。
- **尺寸**：客厅净宽约 8760，餐厅净宽约 2680，南北进深约 6.7 m；含阳台、客厅、书房、餐厅、过道、厨房六部分。
- **窗洞/梁**：南窗 TH 400 / CH 2160；梁 LH 460/500/300（梁底约 2520/2480/2680）。
- **现状**：与餐厅、厨房、玄关连通，没有独立客厅墙；南侧为整面窗+阳台，阳台和客厅连通一体（无独立边界，已封窗；阳台窗为落地窗）。北侧窗户较多，墙面较碎。
- **结构**：客餐厅西南角 810×840 柱、南次卧 220 墙、北次卧 220 墙在客餐厅周边形成三个凸角；横梁多。
- **设计要点**：
  - 不砌墙做分区，用家具、地面材质、灯光和局部吊顶划分“客厅 / 餐厅 / 书房 / 过道”。
  - 客厅靠南窗/阳台布置，餐厅靠厨房布置，书房区以顶部南北向梁/厨房与北次卫墙为界；**85寸移动电视放客厅东侧**，细黑移动支架，不设电视墙；南侧留出通行和采光面。
  - 主灯 + 双眼皮；**窗帘直接装在阳台落地窗上**（电动纱帘+遮光帘），客厅内不另做窗帘；其他位置手动；中央空调沿边吊。
  - 储物柜靠实墙布置（南次卧西墙、客餐厅西南角柱两侧），柜上吊顶；**书房西侧整排到顶储物柜**（见下）。
  - 餐厅北侧为落地窗，冰箱/高柜不挡采光。
- **客厅 / 书房分区**：
  - 以顶部一根**南北朝向的梁**为分界，或以**厨房与北次卫之间的墙**为分界；客厅与书房保持开放，不砌墙。
  - **客厅**：只放一张**黑色电动沙发**，约 3m，面向客厅东侧；**移动茶几在沙发北侧**；85寸移动电视放客厅东侧（细黑移动支架）；不设电视墙，不要传统大茶几/边几堆叠。
  - **书房**：**2.4m 长 × 850mm 宽 × 60mm 厚黑胡桃木独板桌**；两把**带靠背人体工学椅**；书房**西侧整排到顶储物柜**。
  - **储物柜做法（文字化参考）**：整墙到顶、纯色平板门，柜门与墙面同色系（暖白/米白），无拉手/隐藏拉手，竖向极窄分缝（约 3～5mm），柜门与墙面齐平，视觉上像一面墙；下部封闭收纳，不露开放格；哑光门板，与艺术漆墙面有轻微材质层次。
- **立面索引**：EL-05～08（A/B/C/D 四向）。

### 3.2 南次卧（约 11.99 ㎡）

- **位置**：东南角（图左上），南向窗，东侧为邻户/储物间。
- **尺寸**：净尺寸约 2980×3440；图纸面积 11.99 ㎡（含衣柜/墙体口径，净面积约 10.3 ㎡）。
- **窗洞/梁**：南窗 TH 640 / CH 1860；梁 LH 300/350（梁底约 2680/2630）；南窗上口梁做**弧形造型**美化，配合双眼皮/窗帘盒。
- **门/窗**：卧室门开向客餐厅；南次卫门改为从南次卧北墙进入（套内）；南向窗；东侧无窗。
- **现状方案**：床横向布置，床头朝东墙；衣柜沿北墙（约 1504 长），双眼皮吊顶。
- **设计要点**：
  - 这是全屋采光最好的次卧，适合做长辈房/客房套间（带南次卫）。
  - 衣柜进深 600 会压缩通行，建议推拉门或金属衣架+滑门（与主卧衣帽间同体系）；衣柜需避让南次卫新门洞，1504 可能缩短或改到西墙。
  - **南次卫改为套内卫生间**：原客餐厅/门斗侧门封堵，门从南次卧北墙进入；南次卫东墙为**半窗采光**（窗台 1620 / 窗高 1240），排风仍要做。
- **立面索引**：EL-09～11（A/B/C）。

### 3.3 南次卫（约 5.05 ㎡）

- **位置**：东侧，南次卧北侧，属于**南次卧套内**。
- **尺寸**：湿区净尺寸约 1880×1440；5.05 ㎡ 为含外侧洗漱/家政区的口径；**地面下沉 370**；梁 LH 260～350。
- **门/窗**：门开向南次卧（套内）；原客餐厅/门斗侧门封堵；东墙**半窗**（窗台 TH 1620 / 窗高 CH 1240），朝东侧凹槽/储物间，采光有限，按**半明卫**设计；排风、防水仍是重点。
- **设计要点**：
  - 排风、防水是重点；空间小，淋浴区**不做玻璃隔断**（可留浴帘/挡水条），避免压抑。
  - 半明卫墙面用浅色、镜柜、感应灯，减少压抑感；半窗配排风扇或新风。
  - 电器：轻智能马桶、风暖浴霸、浴室柜+镜柜+花洒；洗烘不在这里。

### 3.4 主卧套（约 27.34 ㎡）

- **位置**：西侧（图右侧），由睡眠区 + 主卫 + 衣帽间组成。
- **尺寸**：睡眠区约 3510×3740；主卫约 1530×2230（4.57 ㎡）；衣帽间净宽约 2920。
- **窗洞/梁**：主卧南窗 TH 640 / CH 1860；主卫窗 TH 1010 / CH 1870（主卫下沉 360）；衣帽间北窗 TH 150 / CH 2350、西窗 W-W2 待核；主卧周边梁 LH 320～500（梁底约 2480～2660）。
- **门/窗**：主卧门开向客餐厅西端（即主卧东墙北端）；主卫门在主卫区域北侧；衣帽间与主卧连通（无门）；主卧主窗为南向 W-S3（约 2428，朝南，窗外无设备平台），西墙为主卫/衣帽间隔墙，无直接西窗；衣帽间有西窗 W-W2 + 北窗 W-N7。
- **现状方案**：床头靠东墙（床头朝东，脚朝西侧主卫/衣帽间），床尾朝主卫；主卧东墙 600 深衣柜、西墙 600 深衣柜；衣帽间两排 I 形柜体，不挡窗洞。
- **主卫电器**：轻智能马桶、风暖浴霸、浴室柜+镜柜+花洒。
- **设计要点**：
  - 主卫占西南角，会挡住部分西/南光，这是本户型已知缺点；用玻璃隔断、浅色砖、镜面提亮，避免主卫做成“黑盒子”。
  - 衣帽间按需求做金属衣架 + 铝合金滑门，不做板材柜门；滑轨质量优先。
  - 主卧南窗朝南，窗外无设备平台；下午仍有西晒，主卫/衣帽间西窗是西晒重点。主卧用窗帘盒+遮光帘+纱帘。
- **立面索引**：EL-13～16（A/B/C/D）。

### 3.5 北次卧（约 8.73 ㎡）

- **位置**：北侧（图下方），夹在北次卫与衣帽间之间。
- **尺寸**：净尺寸约 2990×2560；图纸面积 8.73 ㎡（含衣柜口径）。
- **窗洞/梁**：北窗 TH 640 / CH 1860；梁 LH 400（梁底约 2580）。
- **门/窗**：门开向客餐厅北侧走道；北向窗。
- **现状方案**：床头靠南墙（床头朝南），衣柜沿西墙 468 深；按儿童房考虑，5 年内空置。
- **设计要点**：
  - 面积小，家具必须紧凑/定制；不做固定书桌，保留后期调整余地。
  - 北向光弱，墙面用暖白/浅色；主灯 + 局部阅读灯。
- **立面索引**：按立面索引图对应编号（图中 D 向可见）。

### 3.6 北次卫（约 2.92 ㎡）

- **位置**：北侧，厨房与北次卧之间。
- **尺寸**：约 2.92 ㎡，窄长形；**地面下沉 370**；北向高窗 TH 970 / CH 1570（另有 CH 1870 一组，现场核对）；梁 LH 260～300。
- **门/窗**：门开向走道；北向高窗，按明卫考虑。
- **洁具**：**用蹲便器，不用马桶**。蹲便器居中布置，淋浴区在里侧，洗手台外置或选超薄盆；利用 370 下沉做同层排水/防臭。
- **电器**：风暖浴霸 + 排风；不用智能马桶。
- **设计要点**：
  - 空间很小，蹲便器 + 淋浴 + 外置洗手台是可行的三件套；不要放浴缸/大浴室柜。
  - 干湿分离、排风、防水要做足；与厨房共墙，注意防水和异味。
  - 若北次卧 5 年内空置，可先只做蹲便器 + 淋浴 + 基础洗手台，保留升级余地。

### 3.7 厨房 + 餐厅

- **厨房**：约 1990×3150（按现场；旧图 3020），位于北侧，**全开放、无门（不设推拉门）**；**西南角有烟道 460×520（不可拆改）**；**北侧台面 1990×600（水槽）+ 西侧台面 1720×600（灶+备餐）**；北窗 TH 170 / CH 2320；梁 LH 260～300。
- **电器**：油烟机、燃气灶、燃气热水器、洗碗机、冰箱；全屋净水（前置/中央净水/中央软水/厨下 RO/管线机）；不设烤箱/蒸烤箱。
- **吊柜**：**厨房北侧是窗，北墙不做吊柜**；如做，只能放在非窗墙面（西墙/东墙局部），并避开梁。
- **冰箱位置（重点分析）**：
  - 冰箱 **833 宽 × 600 深 × 1910 高**（美的机皇550法式门；按 830/1930 估算）；**放在烟道东侧，南侧与烟道南墙齐**，直接裸露、不包柜；冰箱门**朝东**。
  - 厨房宽 1990 = 烟道 460 + 冰箱深 600 + 东侧通道 930；通道 ≥900。
  - 厨房深 3150 = 冰箱 833 + 西侧净空 1717（按 830 计 1720）+ 水槽台面 600。
  - 冰箱背靠烟道，留 50～100mm 散热/隔热缝；冰箱北侧、烟道以北剩约 310mm，形成 460×310 的小 niche，可做清洁/小储物或留空。
  - 冰箱裸露在南侧，客厅/餐厅能看到；这是本方案的主要代价。
  - **型号/开门**：美的机皇550法式门（MR-550WUFIPZE / 2.0 MR-550WUFJDIZE），833×600×1910，安装预留 ≥837×600×1918；90°直角开门、底部/前部散热、两侧可贴墙（>2mm）；法式对开+下方大抽屉。
  - **930 通道开门**：90°可开；双门同时开会占通道，建议 90°限位/一次开一侧；下方大抽屉拉出留 ≥700；左侧门朝客厅、右侧门朝厨房；确认门板/把手 90° 前伸、餐桌/灶/烟道不碰。
