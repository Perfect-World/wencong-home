# 设计师责任与合同要点

> 适用模式：**设计 + 自己找师傅**（设计施工分离）
> 项目：约 140㎡，全屋通铺 750×1500，墙面艺术漆，含定制柜
> 目的：把"设计师该做什么"写成可验收的条款，避免开工后"图上有、做不了"

---

## 一、一句话定位

设计师 = **出图 + 交底 + 验收把关**，不是项目经理，也不是监理。
他负责"做对"，施工方负责"做好"，你负责"串起来"。

---

## 二、三方责任边界

| 事项 | 设计师 | 施工方（你自己找） | 你（业主） |
|---|---|---|---|
| 方案与施工图 | **主责** | 按图施工 | 确认 |
| 尺寸复核 | 交底时复核 | 进场复尺（墙、地、门洞） | 拍板 |
| 找工人 / 谈价 / 签合同 | 不负责 | — | **主责** |
| 材料下单 / 进场时间 | 出清单、选样 | 提前 3 天报需求 | **主责** |
| 施工质量 | 不承担 | **主责** | 验收 |
| 工序衔接、进度 | 提建议 | 配合 | **主责（项目经理角色）** |
| 收口节点 | **出节点图** | 照图做 | 现场判断归属 |
| 变更 | 出变更图 | 出变更报价 | 确认并签字 |
| 隐蔽工程留档 | 参与验收 | 拍照 + 打压记录 | 存档 |
| 竣工图 | 可另收费 | 不提供 | 要求提供 |

> 关键：**"归谁"要写进合同，不能靠口头默契。**

---

## 三、分阶段责任与交付物

### 阶段 1：前期（量房 → 平面确认）

| 交付物 | 验收标准 |
|---|---|
| 原始结构图（含承重墙标注） | 与现场尺寸误差 ≤ 20mm |
| 2~3 版平面方案 | 每版标注拆改、动线、家具尺寸 |
| 拆改图 | 标出拆/砌位置、尺寸、是否承重 |
| 需求清单确认表 | 逐条对应你的需求列表 |

### 阶段 2：方案深化（效果图 + 材料）

| 交付物 | 验收标准 |
|---|---|
| 效果图（客餐厅 + 主卧，至少 2 个空间） | 与最终施工图一致，不出现"效果图里的东西图上没有" |
| 主材清单 | 品牌/型号/规格/数量/参考价齐全 |
| 色彩与材质板 | 瓷砖、艺术漆色号、柜门板、五金明确到色号 |

### 阶段 3：施工图（**最关键**）

必须逐张交付，缺一张都算未完成：

1. 原始结构图
2. 拆改图（含新建墙体定位尺寸）
3. 平面布置图（家具定位 + 尺寸）
4. 地面铺装图（起铺点、对缝方向、门槛石位置）
5. 天花吊顶图（标高、灯槽、窗帘盒、检修口）
6. **灯位图**（含回路编号）
7. **开关插座点位图**（高度、距墙尺寸、回路）
8. **给排水点位图**（冷热水、地漏、排水坡度方向）
9. 各空间立面图（客餐厅、主卧、厨房、卫生间）
10. 节点大样（门套、窗台、踢脚线收口、柜体与墙交接、艺术漆收边）
11. 定制柜图（立面 + 内部格局 + 尺寸 + 五金位）
12. 空调/新风/地暖配合图（如有）
13. 材料表 + 工艺说明（含艺术漆施工工艺）
14. 图纸目录 + 版本号

> **验收标准**：随便拿一张图给师傅，他能不问你就知道怎么干。
> 做不到，说明图没出完。

### 阶段 4：施工配合

| 服务 | 次数要求 | 说明 |
|---|---|---|
| 开工交底 | 1 次 | 全体工种到场，逐项过图 |
| 水电交底 + 隐蔽验收 | 2 次（交底 1 + 验收 1） | **必须到场**，拍照留档 |
| 防水闭水验收 | 1 次 | 与施工方一起确认 |
| 瓦工验收（空鼓/平整/坡度） | 1 次 | 空鼓率 ≤ 5% |
| 木工/吊顶验收 | 1 次 | 龙骨间距、标高、灯槽 |
| 油工验收（平整度/阴阳角） | 1 次 | 2m 靠尺误差 ≤ 3mm |
| 主材选样陪同 | 2 次 | 瓷砖 + 柜门/艺术漆 |
| 现场答疑 | 不限次（微信群，24h 内回复） | 需写明响应时限 |
| 变更出图 | 按需（含在总价内 N 次） | 超出部分按次收费需提前约定 |

**合计建议写进合同：现场服务不少于 8 次**（交底 2 + 验收 5 + 选样 1），超出按 300~500 元/次计。

### 阶段 5：收尾

- 软装清单（家具、灯具、窗帘、地毯，含尺寸与位置）
- 竣工照片归档
- 竣工图（如需要，单独报价）

---

## 四、明确"不负责"的 6 条（写进合同反而保护你）

1. 不负责找工人、谈价、签施工合同
2. 不承担施工质量与安全问题
3. 不负责材料采购、送货、退换
4. 不负责现场成品保护、垃圾清运
5. 不负责工期与工人协调
6. 不负责保修（施工质保由施工方承担，设计缺陷由设计方承担）

> 第 6 条要反向写清：**因图纸错误导致的返工，由设计方承担返工费**。这是最该争取的一条。

---

## 五、变更管理（最容易扯皮的地方）

```
发现问题 → 微信文字说明 + 现场照片
        → 设计师 48h 内出变更图（标注版本号 V2/V3）
        → 施工方按变更图出报价
        → 你签字确认
        → 施工
```

三条硬性要求：

1. **口头变更无效**，一律走文字 + 图
2. 变更图必须标**版本号和日期**，旧版作废
3. 变更费用在**施工前**确认，不允许"先做后算"

## 六、付款与交付绑定

| 节点 | 比例 | 对应交付物 |
|---|---:|---|
| 签约 | 30% | 平面方案确认 |
| 施工图交付 | 40% | 全套施工图 + 材料表（缺一张不付） |
| 开工交底完成 | 20% | 交底记录签字 |
| 竣工 | 10% | 竣工验收 + 竣工照片 |

> 不要把 80% 在出图前付完，否则后期叫不动人。

---

## 七、可量化的验收标准

| 项目 | 标准 |
|---|---|
| 图纸尺寸 | 与现场实测误差 ≤ 20mm |
| 灯位/插座图 | 每个点位标注：高度、距墙、回路编号 |
| 瓷砖排版 | 起铺点、对缝方向、非整砖位置必须在图上标出 |
| 定制柜图 | 每块板标注厚度、封边、五金型号 |
| 艺术漆 | 标注品牌、色号、遍数、基层处理要求（挂网/墙固） |
| 收口节点 | 门套、窗台、踢脚线、柜墙交接必须有剖面图 |

## 八、常见扯皮点与对应条款写法

| 扯皮场景 | 条款写法 |
|---|---|
| "效果图有，图上没有" | "效果图所示内容须在施工图中完整体现，缺项由设计方免费补图" |
| "师傅说做不了" | "设计方须提供可施工的节点大样，并在交底时向施工方解释工艺" |
| "这不是我设计的，是师傅做错" | "因图纸错误或标注不清导致的返工，返工费由设计方承担" |
| "改一下很快的" | "合同价含 X 次变更，超出按 X 元/次" |
| "我已经交底过了" | "每次交底须有书面记录并由三方签字" |
| "柜子尺寸不对" | "定制柜由商家深化出生产图，设计方负责审核并签字确认" |
| "艺术漆效果不对" | "设计方须提供色板并现场确认首面墙效果后再大面积施工" |
| "验收你没来" | "关键节点验收须提前 24h 通知，设计方无故缺席按 500 元/次扣款" |

## 九、签约前必须问清的 12 个问题

1. 设计费单价？按建筑面积还是套内面积？
2. 包含哪些图纸？**灯位图、水电点位图、节点大样**是否包含？
3. 效果图出几张？哪些空间？
4. 现场交底和验收各几次？超出怎么收费？
5. 出图周期多久？分几次交付？
6. 变更几次内免费？
7. 是否包含主材选样陪同？
8. 是否包含软装清单？
9. 是否包含定制柜图纸？还是只出概念？
10. 施工方看不懂图时，是否负责解释到能施工？
11. 图纸错误导致返工，谁承担费用？
12. 是否有竣工图？另收费吗？

## 十、签约前 checklist

- [ ] 合同写明图纸清单（逐张列，不写"全套施工图"这种模糊表述）
- [ ] 合同写明现场服务次数与响应时限
- [ ] 合同写明变更次数与超次收费
- [ ] 合同写明"图纸错误导致返工由设计方承担"
- [ ] 合同写明付款节点与交付物绑定
- [ ] 合同写明"口头变更无效"
- [ ] 留一份图纸电子版（CAD/PDF）自己存档
- [ ] 确认设计费是否含税、是否开票
- [ ] 确认设计师本人负责，还是转给助理画图
- [ ] 建立三方微信群（你 + 设计师 + 各工种负责人）

---

## 十一、你作为"项目经理"的日常清单

设计师不管进度，这部分你要自己盯：

| 阶段 | 你要做的事 |
|---|---|
| 开工前 | 办物业手续、交底会、材料下单、确定各工种进场时间 |
| 拆改 | 确认承重墙、垃圾清运、验收拆改尺寸 |
| 水电 | 交底到场、打压测试、拍照留档、封槽前验收 |
| 瓦工 | 瓷砖到场核对色号批次、闭水试验 48h、空鼓检查 |
| 木工 | 吊顶标高复核、窗帘盒尺寸、灯槽预留 |
| 油工 | 挂网/墙固确认、平整度验收、艺术漆首面墙确认 |
| 安装 | 门、柜、洁具、灯具、开关面板按序进场 |
| 收尾 | 开荒保洁、补漆、软装进场 |
