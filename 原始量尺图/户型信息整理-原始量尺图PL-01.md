## 二、方位与读图说明

### 1. 方位（按你确认的方向）

图纸已旋转，**读图方位为：上南、下北、左东、右西**。

| 图面方向 | 实际方位 |
|---|---|
| 图的上方 | **南** |
| 图的下方 | **北** |
| 图的左方 | **东** |

- **阳台位于南侧（图的上方）**。
- 南墙为主要采光面，中段为大推拉门。

### 2. 标注代号

| 代号 | 含义 | 说明 |
|---|---|---|
| **TH** | 窗台高度 | 完成地面至窗台下沿 |
| **CH** | 窗洞高度 | 窗台下沿至窗顶；**TH + CH = 窗顶距地** |
| **LH** | 梁高 | 梁自顶板向下垂吊尺寸；**梁底净高 = 层高 − LH** |
| **下沉** | 地面降板高度 | 卫生间等区域地面下沉高度 |

### 3. 墙体图例

- **黑色实心粗墙 / 黑色方块**：承重墙、剪力墙及结构柱，**不可拆改**。
- **白色细墙**：轻质隔墙，可调整（施工前需与物业 / 结构确认）。

## 九、需现场复核

1. **承重墙不可拆**：黑色粗墙及结构柱严禁拆除、开洞；白色隔墙调整前需与物业 / 结构确认。
2. **尺寸链存在差值**：各墙分段净尺寸之和小于外轮廓总尺寸，差值为墙厚累积及可能漏标，应以现场复尺为准：
   - 南墙：2980+8760+2480+1530 = **15750**，总 **16820**；
   - 北墙：2680+1990+1650+2990+2920 = **12470**，总 **13420**；
   - 东墙：3440+1440+1940+2420 = **9240**，总 **10300**。
3. **三个卫生间均降板**（360 / 370），注意回填方式与防水高度。
4. **局部梁下吊较深**（LH490 / LH500），吊顶及柜体设计需避让。
